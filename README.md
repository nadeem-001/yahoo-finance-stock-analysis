# Yahoo Finance Stock Analysis (Learning-Based Project)

This project was created as a learning exercise to understand how stock market data can be analyzed using Python and publicly available data from Yahoo Finance. The focus of this project is on exploring price trends, technical indicators, and basic machine learning concepts.

## What I worked on
- Collected historical stock price data using the Yahoo Finance (yfinance) API
- Prepared and cleaned time-series data for analysis
- Calculated the Relative Strength Index (RSI) to study overbought and oversold conditions
- Performed exploratory data analysis to visualize price movements and trends
- Created simple classification labels based on RSI thresholds
- Applied Logistic Regression and Support Vector Machine (SVM) models for practice and learning

## Tools & Technologies
Python, Pandas, NumPy, yfinance, Scikit-learn, Matplotlib, Jupyter Notebook

## Note
This is a learning-based project intended to practice financial data analysis and introductory machine learning techniques using public datasets.
